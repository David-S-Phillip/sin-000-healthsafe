# How to add the pom.xml as a maven project
## When intelli j is on tik 
Sometimes intelli j doesn't recognise the pom.xml file for the different microservice programs. 
do the following to ensure it does pick it up.

* ***Open the Maven Panel***
Look at the right edge there should be a m in bold, if you dont see it got to the top menu bar: View -> Tool Windows -> Maven

* ***Manually add the project***
In the Maven panel, click the + icon and then Add Maven Projects and select the pom.xml file.

* **Reload the project***
Please be patient, your a student not a SE, wait for all the dependencies to download and if there are still errors well welcome to WeThinkCode_.
